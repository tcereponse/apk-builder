# RESPONSIVE MOBILE-FIRST — JACK

## 1. Stratégie Mobile-First
- **Approche** : Tailwind CSS avec classes `sm:`, `md:`, `lg:`, `xl:`, `2xl:`
- **Breakpoints** :
  - `sm` : 640px (tablette)
  - `md` : 768px (tablette paysage)
  - `lg` : 1024px (desktop)
  - `xl` : 1280px (grand écran)

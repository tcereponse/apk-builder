# DevPortfolio

Portfolio développeur élégant avec sections projets, compétences, expérience et contact. Animations au scroll, thème sombre, responsive.

## 🚀 Démarrage rapide

```bash
npm install
npm run dev
```

Le serveur de développement démarre sur http://localhost:5173

## 📜 Scripts disponibles

| Script | Description |
|--------|-------------|
| `npm run dev` | Démarre le serveur de développement (avec vérification TS) |
| `npm run build` | Build de production |
| `npm run preview` | Prévisualise le build de production |
| `npm run verifySyntax` | Vérification TypeScript (tsc --noEmit) |


## 🛠️ Stack technique

- **React** 18
- **Build tool**: vite
- **TypeScript** 5
- **Styling**: tailwind
- **Routing**: React Router DOM v6 (HashRouter)
- **UI Library**: shadcn
